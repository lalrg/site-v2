# Specs

One file per feature or change worth thinking about before coding.
Filename: `YYYY-MM-DD-<slug>.md`. A spec states the problem, the requirements,
the non-goals and the acceptance criteria; it does not prescribe tickets.

Spec template: `~/.config/opencode/templates/spec.md`.
Design decisions that outlive the spec go into the **Architecture** section of
the root `AGENTS.md`, or `../architecture.md` once that file is warranted.
